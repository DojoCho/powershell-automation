# Microsoft 365 PowerShell Scripts

PowerShell automation scripts for Microsoft 365 administration and reporting.

## Requirements

- PowerShell 7+
- Microsoft Graph PowerShell SDK
- Appropriate Microsoft 365 / Microsoft Entra permissions

## Scripts

| Script | Description |
|---|---|
| `Connect-M365.ps1` | Connects to Microsoft Graph using delegated permissions |

## Authentication

Scripts use Microsoft Graph PowerShell authentication and do not store passwords, secrets, or tenant credentials.

## Disclaimer

These scripts are intended for learning, administration, and automation purposes. Test in a non-production environment before using them in production.
